# Day 4: Networking
ip a              -> my IP (private)
ip route          -> gateway
curl ifconfig.me  -> public IP
sudo ss -tlnp     -> who listens on which port
dig +short NAME   -> DNS: name to IP
curl -I URL       -> HTTP status code
openssl s_client  -> certificate expiry
Ports: 22 SSH, 80 HTTP, 443 HTTPS, 53 DNS, 3306 MySQL
Codes: 200 OK, 301 redirect, 404, 502/503/504
